# AGENTS.md

Instructions for AI coding agents working in this repository.

Start here, in this order:

1. [`Agent/PROJECT_SUMMARY.md`](Agent/PROJECT_SUMMARY.md): what NetSilcon is, layout, maths, protocols, results, how to verify
2. [`Agent/WORKING_RULES.md`](Agent/WORKING_RULES.md): how changes are made (Python model -> Verilog -> simulation -> hardware), honest numbers, git
3. [`Agent/MODEL_INDEX.md`](Agent/MODEL_INDEX.md): every trained model with its CRC and results
4. The `README.md` of the model folder you work in (`NetSilcon-Models/<model>/`)

Run commands from inside the model folder. Never claim a number that no log or test output shows.
Setting up a fresh clone: paste the prompt from [`Agent/SETUP_PROMPT.md`](Agent/SETUP_PROMPT.md).
