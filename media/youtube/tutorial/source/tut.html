What you need

A PC

Windows, Linux or macOS. On Windows, run the test scripts in WSL Ubuntu (or Git Bash).

Python 3 + numpy · Icarus Verilog

for training and simulation · pyserial for the board

Sipeed Tang Nano 20K

FPGA Gowin GW2AR-18, connects over USB-C

Gowin EDA, Education edition

free, builds the bitstream

Step 3

Build the bitstream in Gowin EDA

1
New project · device GW2AR-LV18QN88C8/I7 (GW2AR-18C)
2
Add files
rtl/ns64_requant.vrtl/ns64_wram.vrtl/ns64_engine.vboard/ns_uart.vboard/ns64_uart_tx.vboard/ns64_loader.vboard/tangnano20k_ns64.vboard/tangnano20k_ns64.cstboard/tangnano20k.sdc
3
Copy fpga/gen/wmem_00.mem … wmem_31.mem next to the .gprj file (the built-in model)
4
Top module tangnano20k_ns64 · include path fpga/gen · Synthesize → Place & Route

Trap: Gowin compiles its own copies in src/

Changed a .v file in the repo? Copy it into the Gowin project again before you synthesize.

expected: logic 35 % · BSRAM 32 / 46 · DSP 16 / 24
Step 4

Program the board

Tools → Programmer

Cable: USB Debugger A · 0.9 MHz
Device: GW2AR-18C
Operation: SRAM Program
File: impl/pnr/ns64.fs

LED0 blinks = alive

SRAM is lost at power-off

after unplugging, program it again

Step 8

Use it in your program

scale_inputs()

real readings → 16 inputs 0..127, using the ranges stored in the model file

chip.infer()

send the 16 inputs over UART, read 16 outputs back

decode()

outputs → class name, or values in real units

readings → scale → send → decode → decision

send: A5 x0 … x15 (17 bytes)
reply: 5A y0 … y15 argmax lat (20 bytes)
any UART · 115200 baud · 8N1 · PC, STM32, ESP32, Arduino

Windows tip

set the serial timeout once, never change it: each change resets the board's USB bridge
